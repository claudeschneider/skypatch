# Changelog

Every new commit receives an incremented version. Earlier commits are recorded below without rewriting their history.

## 0.3.0 — 2026-09-09

- Pan and zoom while drawing a sky patch: Space-drag and scroll on desktop, or two-finger pan/pinch on mobile. Single taps add corners.
- Fixed the release helper so version bumps run correctly.

## 0.2.0 — 2026-09-09

- Added a public website changelog and a latest-release summary on GitHub.
- App updates now show a readable release version alongside the build identifier.
- Refreshed the feature tour for multiple object types, equipment presets, constellation modes and PWA updates.

## Earlier updates — 2026-09-09

- Commit 202e821: added new-version notifications, Update now / Later, manual update checks and an installed-build display. Updates preserve saved settings and survey downloads.
- Commit 242f2f4: added multiple object-type selections, alternate object names, offline DSO descriptions, smart-telescope and DSLR presets, and Off / Focus / Full constellation modes. Removed the desktop Hide panel button.
- Commit 5ed02f6: published the interactive planetarium, target filters, accurate telescope and mosaic framing, solar-system scale previews, visible-sky polygons, mobile controls, offline PWA and feature website.
